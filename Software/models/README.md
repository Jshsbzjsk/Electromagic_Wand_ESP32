# 手势模型与数据集参考

本目录保存参考项目的手势数据集、测试数据和 TensorFlow Lite 模型或转换后的 `model.h` 文件。

## 历史版本

- `1030_5/`：约 64 Hz、2 秒窗口，历史说明中使用 Y/Z 轴，时序长度为 128。
- `0908_6/`：约 100 Hz、2 秒窗口，历史说明中使用 Y/Z 轴，时序长度为 200。
- `0922_6/`：约 100 Hz、2 秒窗口，历史说明中使用 Y/Z 轴，时序长度为 200。
- 其他目录：保存 Circle、Horn、Letter Phi、Letter W、Right Angle、Up and Down 等动作的数据。

历史资料中出现过约 90% 或 95% 的识别率描述，但没有统一的测试集、测试流程和复现记录，因此不能作为当前项目性能指标。

这些模型属于参考项目。使用前必须确认输入轴顺序、采样率、时间窗口、归一化方式和输出标签与目标固件一致。
